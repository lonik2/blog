Este proyecto consiste en un portafolio que incluye un blog adentro del mismo. Este blog contiene posts, categorias y comentarios.

requerimientos:
- django 6.1.1
- python 3.13.14

Para correr este repo se tiene que abrir la terminal y luego ejecutar los siguientes comandos en orden:
- cd django_blog
- python manage.py runserver

Esto te llevara al portafolio, en donde se encuentra las secciones normales, como inicio, sobre mi, proyectos y contactos. Tambien se encuentra la seccion de blog, que te lleva a la parte principal de este proyecto.
